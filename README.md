# چرم بهبد | BehbodShop

فروشگاه اینترنتی محصولات چرمی دست‌دوز ایرانی.

## وضعیت پروژه

این پروژه در حال تبدیل‌شدن از یک نمونه‌ی اولیه‌ی استاتیک (HTML/CSS/JS) به یک پلتفرم
full-stack واقعی است — با بک‌اند، دیتابیس، احراز هویت، و پنل مدیریت.

## نقشه‌ی راه

- [x] نسخه‌ی اولیه‌ی استاتیک (storefront prototype)
- [ ] راه‌اندازی بک‌اند (NestJS + PostgreSQL + Prisma)
- [ ] احراز هویت و مدیریت کاربران
- [ ] مدیریت محصولات و دسته‌بندی‌ها
- [ ] سبد خرید و سفارش‌ها
- [ ] پنل مدیریت
- [ ] بازسازی فرانت‌اند با Next.js

## تکنولوژی‌ها (برنامه‌ریزی‌شده)

- Backend: NestJS, PostgreSQL, Prisma
- Frontend: Next.js, React
- Auth: JWT
